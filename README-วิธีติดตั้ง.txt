ระบบจัดตารางสอนแทน (แอปติดตั้งได้)

ไฟล์ในโฟลเดอร์นี้ต้องอัปโหลดไปไว้ด้วยกัน ห้ามแยกไฟล์:
  index.html, manifest.webmanifest, sw.js, icon-*.png

ขั้นที่ 1 นำขึ้นเว็บ (เลือกวิธีเดียว)
  วิธี A: Netlify (ง่ายที่สุด)
    1) สมัครบัญชีฟรีที่ netlify.com
    2) เข้าหน้า Add new site > Deploy manually
    3) ลากโฟลเดอร์ที่แตกไฟล์ zip แล้ววาง ได้ลิงก์ลักษณะ https://ชื่อ.netlify.app
  วิธี B: GitHub Pages
    1) สมัคร github.com สร้าง repository ใหม่ (Public)
    2) อัปโหลดไฟล์ทั้งหมดเข้า repository
    3) Settings > Pages > เลือก branch main โฟลเดอร์ / (root) > Save
    4) รอสักครู่ จะได้ลิงก์ https://ชื่อผู้ใช้.github.io/ชื่อ-repository/

ขั้นที่ 2 ติดตั้งบนโทรศัพท์
  iPhone (Safari): เปิดลิงก์ > ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม
  Android (Chrome): เปิดลิงก์ > เมนู ⋮ > ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก

การเก็บข้อมูล
  ข้อมูลทั้งหมดเก็บในโทรศัพท์เครื่องที่ใช้ ใช้ปุ่ม "สำรองข้อมูล" ในเมนูด้านข้างเพื่อดาวน์โหลดไฟล์สำรอง
  และปุ่ม "กู้คืนข้อมูล" เพื่อนำกลับมาเมื่อเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์
  อย่าลบ "ข้อมูลเว็บไซต์" ของเบราว์เซอร์ เพราะข้อมูลจะหาย

การอัปเดตแอป
  เมื่อได้ไฟล์ index.html ใหม่ ให้อัปโหลดทับ และแก้เลข v1 ในไฟล์ sw.js เป็น v2 (หรือสูงกว่า)
